# Lista de entrega

1. Instalar SQL Server Express.
2. Ejecutar database/database.sql.
3. Instalar Node.js 18+.
4. Ejecutar npm install.
5. Configurar .env.
6. Ejecutar npm run dev.
7. Probar GET /api/health.
8. Crear repositorio GitHub.
9. Subir el proyecto.
10. Entregar el PDF junto con el enlace del repositorio.
